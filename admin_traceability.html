🔑
GitHub API Token — Required for All Admin Saves Do Not Hardcode
Every admin page that writes to JSON uses a GitHub Fine-Grained PAT stored in localStorage.getItem('amayaa_gh_token').
To set it: Admin → Settings → scroll to bottom → GitHub Token field → Save Token.
Token is stored in the browser only — never committed to git. Required scopes: Contents: Read & Write on repo Amayaa-2026/amayaa-website.
If a Save button shows "No GitHub token" alert → go to Settings and re-enter. Token resets if browser data is cleared.
